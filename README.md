# 考试编排小工具

下载 `index.html`，用浏览器打开即可离线使用。学生名单在本机处理。

1. 粘贴名单或导入电子表格。导入前核对答题卡要求的考号位数和前导零。
2. 设置考场、座位数和编排方式，点击「开始编排」。
3. 导出 Excel 名单，按班级或考场查看和打印。

无表头时，工具会尝试识别数字考号、两到四个汉字的姓名和班级。班级与考号都是纯数字且无法区分时，请添加表头。
